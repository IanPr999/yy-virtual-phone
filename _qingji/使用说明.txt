轻记 v1.0.0

安装
1. 不需要解压此 ZIP。
2. 小手机 → 应用市场 → 创作 → 导入整包，选择 QingJi-1.0.0.zip。
3. 确认只申请 App 自身数据读写权限，点击「本机测试」。
4. 安装后桌面会出现「轻记」，也可从应用市场「已安装」中打开。

使用
- 今日：按公斤记录晨间/晚间体重，切换日期可补记。每天同一时段只保存一条，后续修改会更新这一条。
- 运动：点击种类立即记一次，默认当前点击时刻的时分；在补记日期页点击时，使用选中日期与当前时分。点记录可改日期/时间或删除。
- 运动种类初始为爬坡、游泳、私教课；可添加、改名、移除。历史记录保留当时的名称。
- 趋势：自然周（周一到周日）与自然月，晨重和晚重两条线，目标为虚线，运动以日期下的小点标记。空缺不补零、不跨空缺连线。
- 首页目标差距：优先参考所选日期及之前最近一次晨重；没有晨重时明确标注参考的晚重。
- 调色盘：独立主题、自定义 CSS、复制/导入/导出/清空/应用保存。壁纸与字体在包内，编辑区只有可修改样式。
- 设置：导出 JSON 记录备份；导入时先核对并确认合并。相同日期时段、相同运动编号与目标以导入文件为准，其他记录保留，美化保持不变。

保存与更新
- 安装后使用 window.AiPhone.db 保存本 App 私有数据，不读取聊天、角色或其他 App 数据，也不调用 AI。
- 更新请使用应用市场「换包」，沿用现有 App；导入整包新建安装会获得独立存档。
- 建议在更新、换设备或卸载前导出记录备份。
- 单独在浏览器打开 HTML 为本机浏览器预览，其数据不会自动迁移到小手机；可导出 JSON 后在小手机导入。

验证范围
按 Float 源码 8ef9e34 的 ZIP 解析器与沙盒 SDK 桥接检查；包含记录增删改、目标计算、趋势缺测、备份往返、存储错误保护和屏幕适配。实际安装仍以你的小手机版本为准。
